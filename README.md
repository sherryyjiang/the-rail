# The Rail

Home-game poker cashier. Add players, log buy-ins and cash-outs, then settle who pays whom.

Built for Sat 29 Aug 2026. Works on a phone. Numbers stay in this browser.

## Use it

1. Open the site.
2. Add names as people sit.
3. Buy-in (default $100). Rebuys are extra buy-ins on the same seat.
4. Cash out when someone leaves. They can sit back down.
5. When everyone is cashed out, it lists **A pays B $X**.

No login. Undo and reset are in the page.

## Save past nights

Use the **Save** button to snapshot the current game with a custom name. Your active game stays on screen — saving never clears it. Tap **Nights** to browse saved games. Viewing a past night is read-only; **Back to tonight** returns to your live game. Refreshing or redeploying doesn't wipe localStorage; your current game and saved nights persist in this browser.
